# Apotek Karima Kudus

Website resmi Apotek Karima Kudus, Mejobo, Kabupaten Kudus.
Domain: https://apotek-karima.vercel.app

## Mengisi event
Buka `index.html`, cari `const EVENTS = [` lalu tambahkan satu baris per event:

    {title:"Judul event", type:"Promo", start:"2026-12-07T08:00", end:"2026-12-07T11:00", time:"08.00 – 11.00 WIB", desc:"Keterangan singkat."},

`type` bisa `Promo`, `Edukasi`, atau `Kesehatan`.
